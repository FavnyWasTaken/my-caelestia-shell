## About

This repository is my personal fork of [Caelestia Shell](https://github.com/caelestia-dots/shell). I made a few configuration changes to fit the look and setup of my dotfiles.

The fork is intended to be used together with [my-dots](https://github.com/FavnyWasTaken/my-dots). It is customized for that setup and may not work as expected with other configurations.

## Changes

- Based on Caelestia Shell `v2.5.0`
- Includes 17 upstream commits from the original repository
- Includes my own configuration changes for my dotfiles
- Follows the monochrome theme of my desktop setup

This is a personal fork, not a general-purpose replacement for the upstream project.

## Installation

For the intended setup, install this shell as part of my dotfiles:

[**Favny’s dotfiles →**](https://github.com/FavnyWasTaken/my-dots)

For standalone installation or general Caelestia Shell documentation, see the [upstream README](https://github.com/caelestia-dots/shell).

## Compatibility

This fork is configured for my Arch-based setup, particularly Arch Linux and CachyOS. Your mileage may vary with other distributions or desktop configurations.
